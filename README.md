# 仮想神経回路 v021

v020を基盤に、標準座標系を想定したメッシュ・parcel対応層を追加した3Dアトラス初期版です。

## 追加内容
- 三角形メッシュ描画
- 38 bilateral parcelの参照アトラス
- 座標空間・出典メタデータ
- 活動値をメッシュ表面へ反映
- 半球・切開・選択領域隔離との連動
- 外部JSONメッシュ読込
- 軽量参照データを同梱

## 既存モデルの点検・修正
- v019～v020の修正を継承
- メッシュ頂点／面数に読込上限を設定
- 同梱形状をMRI由来と誤認しない表記
- 実測アトラスと概念モデル領域をmodelRegionIdで分離

## 起動

静的表示だけなら `public/index.html` をHTTPサーバーで開きます。Python計算は `start_all.bat` または `./start_all.sh` を使用してください。

## 注意

本システムは仮説検証・可視化用の概念モデルです。人間の脳の再現、診断、治療判断には使用できません。
